# Balogh Levente – Webprogramozás beadandó

Reszponzív weboldal Balogh Leventéről, magyar vállalkozóról és befektetőről. A feladat HTML, CSS és Bootstrap 5 használatával készült.

## Funkciók

- Reszponzív elrendezés (Bootstrap 5 grid rendszer)
- Tableten és felette 3 oszlopos kártyaelrendezés
- Tablet alatt egyoszlopos megjelenés, kép és szöveg egymás mellett a kártyákon belül
- Egyedi CSS stílusok (kártya háttér, listajelek, hover effekt, idézet)
- Sötét fejlécű táblázat a befektetésekkel

## Használt technológiák

- HTML5
- CSS3
- Bootstrap 5.3.5
